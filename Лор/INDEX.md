This file is a compact map of the lore library in this folder. Use it to decide which source files to open first for campaign-related questions.

## Spoiler Tags

- `[Содержит спойлеры DiA]` — the file includes serious spoilers for *Baldur's Gate: Descent into Avernus* and the Alexandrian Remix, but may also contain safe public lore. Use it for context, but do not reveal spoiler details to a player-facing user unless they directly ask for spoilers or the DM requests them.
- `[Осторожно: DiA]` — may reveal adventure-route context, NPC roles, or setup details. Use carefully in player-facing answers and keep spoiler details out unless directly requested.
- `[Содержит спойлеры ToA]` — the file includes spoilers for *Tomb of Annihilation*. It may still contain useful Chult lore, but do not reveal adventure-specific details unless directly requested.

Player-facing rule of thumb: public setting facts, public offices, famous people, geography, laws, and everyday culture are safe to use for character creation. Do not reveal that a person, faction, artifact, or location will matter later in the campaign unless the user directly asks for campaign spoilers. For example, Duke Ulder Ravengard can be mentioned as a known public figure; his adventure-specific role should not be volunteered.
