# Дайджест источника: Лорный индекс

## Сырой источник

- `Лор/INDEX.md`

## Что делает этот источник

Это навигационная карта лорной библиотеки, а не самостоятельная лорная статья. Его задача - направлять читателя к самому конкретному справочному файлу Забытых Королевств для любого кампанийно-смежного вопроса по сеттингу.

## Ключевые выводы

- `Лор/` уже работает как организованная библиотека источников.
- Набор лора покрывает космологию, Врата Балдура, фракции, богов, народы, регионы и магические темы, важные для кампании.
- Лучший рабочий процесс: считать `Лор/INDEX.md` первой остановкой для мировых вопросов, а вики - поддерживаемым синтезом для вопросов кампании.
